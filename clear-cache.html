🧹 Solusi 2: Clear Browser Cache


            
Option A: Hard Refresh

            

                
Tekan tombol di bawah atau keyboard shortcut:

                
                
Windows: Ctrl + Shift + R atau Ctrl + F5

                
Mac: Cmd + Shift + R

            


            
Option B: Clear Site Data

            

                
Ikuti langkah ini:

                
    
                    
  1. Klik icon gembok/lock 🔒 di address bar
    2. 
                    
  2. Klik "Site settings"
    3. 
                    
  3. Scroll ke "Usage" atau "Clear data"
    4. 
                    
  4. Klik "Clear site data"
    5. 
                    
  5. Refresh halaman (F5)
    6. 
                

            


            
Option C: Buka di Incognito Mode (PASTI BERHASIL)

            

                
Buka Swagger UI di Incognito/Private Window:

                
                
Chrome: Ctrl + Shift + N, lalu buka localhost:8080/swagger/index.html

                
Edge: Ctrl + Shift + P, lalu buka localhost:8080/swagger/index.html

                
Firefox: Ctrl + Shift + P, lalu buka localhost:8080/swagger/index.html

📝 Solusi 4: Curl Commands (Terminal)

            

                Health Check:

                curl http://localhost:8080/ping



                Create Product:

                curl -X POST http://localhost:8080/api/v1/products \

                  -H "Content-Type: application/json" \

                  -d '{"name":"Gaming Laptop","description":"High-performance gaming laptop","price":1500,"stock":10}'



                Get All Products:

                curl http://localhost:8080/api/v1/products



                Get Product by ID:

                curl http://localhost:8080/api/v1/products/1



                Update Product:

                curl -X PUT http://localhost:8080/api/v1/products/1 \

                  -H "Content-Type: application/json" \

                  -d '{"name":"Updated Laptop","description":"Updated description","price":2000,"stock":5}'



                Delete Product:

                curl -X DELETE http://localhost:8080/api/v1/products/1
